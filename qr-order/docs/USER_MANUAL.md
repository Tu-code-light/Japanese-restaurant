# User Manual

## Customer

1. Scan the QR code printed for the table.
2. The app opens the menu for that table.
3. Select dishes and quantities.
4. Review the cart and send the order.
5. Keep the order page open to receive status updates.

The same QR should not be reused for a different table. If the table is not found or the QR is invalid, show the staff for assistance.

## Staff

1. Open `/staff/login`.
2. Sign in with a staff account.
3. Open the dashboard to view new and active orders.
4. Accept and progress an order through confirmed, preparing, and served states.
5. Use checkout from the table workflow after payment.

## Manager

The manager account can access staff pages plus table management, menu management, and sales reports.

- Add, edit, disable, or remove categories and products.
- Create, edit, or regenerate table QR codes.
- Review sales data and active order status.

Production deployments must replace all sample credentials and restrict network access and CORS origins.
